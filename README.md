# 🚀 Project X

**Project X** is a cross-platform botting platform built for both **RS3 and OSRS**, with a focus on performance, flexibility and giving developers the tools they need to build powerful scripts.

### 🎮 RuneScape Support

* **RuneScape 3**
* **Old School RuneScape**
* Script development APIs
* Client-side tooling
* Automation frameworks
* Cross-platform support

### 🖥️ Platform

* Windows
* Linux
* OpenGL
* Vulkan
* Java-based development ecosystem
* Modular client architecture

### 🧩 Built For Developers

Project X isn't just a client. The goal is to provide a complete ecosystem for building, testing and running scripts.

```text
Project X
│
├── Client
│   ├── RuneScape 3
│   └── Old School RuneScape
│
├── Scripting API
│   ├── Automation
│   ├── Game interaction
│   ├── Client APIs
│   └── Utilities
│
├── Graphics
│   ├── OpenGL
│   └── Vulkan
│
└── Ecosystem
    ├── Scripts
    ├── Developers
    └── Community
```
